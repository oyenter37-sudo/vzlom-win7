# Пранки для Windows 7

Два полноэкранных прикола на чистом Win32 + GDI. Оба — 32-битные EXE со
статической линковкой: работают на слабых ПК (Pentium 4 / 512 МБ ОЗУ) и на
Windows XP / 7 / 8 / 10 / 11 (x86 и x64), без .NET / Python / DLL / установки.

## 1. Vzlom.exe — анимация «Взлом!»

- Чёрный экран, зелёный «матричный» дождь, надпись **Взлом!**
- Кнопки **НАЧАТЬ ВЗЛОМ** и **ОТМЕНИТЬ**
- Сценарий ~60 секунд: скан сети → подбор пароля → повышение привилегий →
  копирование файлов → заражение вирусами → удаление следов → вспышка и резкое закрытие
- Ничего кроме анимации: нет сети, нет файлов, нет реестра, ничего не удаляется и не шифруется

| Клавиша | Действие |
|---|---|
| Enter / Space | начать взлом |
| Esc | выйти |
| «ОТМЕНА» во время анимации | вернуться на главный экран |

## 2. Blok.exe — блокировка ввода

- Клавиатура и мышь не работают: перехват через низкоуровневые хуки
  `WH_KEYBOARD_LL` + `WH_MOUSE_LL` (нажатия, колесо, движение)
- Курсор жёстко дрожит, дёргается по экрану и иногда нарезает круги
- Сверху вниз падают случайные английские буквы (A–Z), со временем чаще
- Чёрный экран, надпись в центре, статус `SYS.INPUT: OFFLINE`
- Выход — **удерживать 5 секунд** комбинацию **Esc + R + правый Ctrl + Delete**
  (на экране не подсказывается; пока держишь, рамка экрана накаляется — по ней видно прогресс)
- Если комбинацию не нажали, окно висит бесконечно — автосброса по таймеру нет.
  Сверху справа тикает счётчик `LOCK mm:ss` (сколько уже держит)
- **Автозапуск:** при старте прописывает себя в
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (значение `Blok`). Поэтому выключение
  или перезагрузка ПК не спасают — после входа в систему окно поднимется снова
- Корректный выход комбинацией **удаляет** эту запись из автозапуска
- Убрать вручную (если очень надо): закрыть комбинацией **или** удалить значение
  `Blok` в `regedit` → `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`,
  либо в консоли: `reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v Blok /f`
- Второй экземпляр не запускается (именованный mutex), двойной блокировки не будет
- Ctrl+Alt+Del не перехватывается — это системная аварийная комбинация, она всегда работает
- Ничего не шифрует и не удаляет: только перехват ввода, пока окно открыто

## Сборка

Собирается автоматически в GitHub Actions (`.github/workflows/build.yml`):

```
i686-w64-mingw32-gcc -std=c99 -O2 -s -municode -mwindows \
    -o dist/Vzlom.exe src/vzlom.c -lgdi32 -luser32

i686-w64-mingw32-gcc -std=c99 -O2 -s -municode -mwindows \
    -o dist/Blok.exe src/blok.c -lgdi32 -luser32
```

Готовые файлы: вкладка **Actions** (artifact) и **Releases** (по тегу `v*`).
